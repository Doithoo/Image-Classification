# Core Package

[简体中文](README.zh-CN.md)

This is the installed `garbage_classifier` package. Start with the runnable
[`examples/`](../../examples/) and the [Code Tour](../../docs/code-tour.md), then
use this page as a map of the production implementation.

## Train command call flow

```text
garbage train
  → cli.main()                    parse command-line arguments
  → cmd_train()                   resolve one ExperimentConfig
  → config.load_config()          defaults + YAML + overrides
  → training.train_from_config()  build data, loaders and model
  → models.create_model()         return nn.Module from registry
  → training.Trainer.fit()        epoch loop and validation
  → Trainer._run_epoch()          forward, loss, backward, update
  → checkpoint.save_checkpoint()  best.pt and last.pt
```

## Package map

| Module | Input | Output | Read when |
|---|---|---|---|
| `config.py` | YAML and overrides | `ExperimentConfig` | Understanding settings |
| `data/` | class folders/manifests | tensor batches | Learning the data pipeline |
| `models/` | model name, classes | `nn.Module` | Choosing/building models |
| `training/` | config, model, loaders | checkpoints, metrics | Learning optimization |
| `evaluation/` | checkpoint, split | report, errors, plots | Measuring a model |
| `inference/` | checkpoint, images | probabilities, CAM, ONNX | Using a trained model |
| `utils/` | small runtime values | device, seed, logging helpers | When referenced |
| `cli.py` | terminal arguments | calls the modules above | Learning application wiring |

## Read in layers

1. `data/dataset.py`, `data/transforms.py`, `models/registry.py`.
2. `training/train.py`, then the `BASIC LOOP` in `training/trainer.py`.
3. `evaluation/metrics.py`, `inference/predictor.py`.
4. `mixup.py`, `ema.py`, `checkpoint.py`, manifest private helpers.

`models/legacy_models/` contains optional hand-written architecture references.
It is not the normal model creation path. Full configuration documentation is in
the [Config Reference](../../docs/config-reference.md).

## Generated sibling directory

`src/garbage_classifier.egg-info/` is generated by editable installation. It is
not source code, is ignored by Git, and can be deleted with `make clean`; the
installer recreates it when needed. Do not edit or study its generated files.
